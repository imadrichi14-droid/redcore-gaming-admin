REDCORE GAMING — version avec panneau de gestion local

POUR L'OUVRIR
1. Décompresse redcore-gaming.zip.
2. Ouvre le dossier redcore-gaming.
3. Double-clique sur index.html.

POUR GÉRER LES PRODUITS SANS MODIFIER LE CODE
1. Dans le site, clique sur « ⚙ Gestion » en haut.
2. Mot de passe de démonstration : RC2026.
3. Ajoute/modifie/supprime des produits, prix, catégories, descriptions et photos.
4. Les images doivent faire moins de 1 Mo.
5. Les modifications sont sauvegardées dans le stockage local de ce navigateur.

LIMITES IMPORTANTES
- Cette version est un prototype local. Les changements sont visibles seulement dans ce navigateur/profil et ne sont PAS synchronisés vers les appareils des clients.
- Le mot de passe dans cette démo n'est pas une vraie protection de sécurité. Ne publie pas cette version telle quelle avec des données sensibles.
- Pour un vrai magasin en ligne, il faudra héberger le site, utiliser une base de données et un stockage d'images partagés, et ajouter une authentification administrateur sécurisée.
- Les produits et prix initiaux sont des exemples : remplace-les par les tiens.
- Le bouton WhatsApp est désactivé jusqu'à ce que le numéro soit configuré dans script.js (ligne WHATSAPP_NUMBER). Format marocain : 2126XXXXXXXX, sans + ni espaces.
